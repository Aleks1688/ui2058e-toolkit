# Папка результатов

Сюда пишутся замеры по умолчанию. В окне замера папку можно сменить
кнопкой **«Папка замеров»** — тогда таблица и архивы будут писаться
туда, а здесь останется только `config.json` с выбранным путём.

Содержимое **не попадает в git** (см. `.gitignore`), кроме этого файла:
данные измерений остаются на рабочей машине.

```
master.csv      общая таблица, одна строка на замер
master.xlsx     она же в Excel (жирная шапка, закреплена первая строка)
records/        архив по замерам: строка на цикл + min/max/rms осциллограмм
waves/          отсчёты осциллограмм (если включён флажок в окне)
config.json     запомненный оператор и папка замеров (создаётся окном)
```

Файлы создаются автоматически при первом замере; удалять их вручную
не нужно. Порядок колонок описан в [../docs/workflow.md](../docs/workflow.md).

Если нужно начать таблицу заново — закройте `master.xlsx` в Excel,
переименуйте `master.csv`/`master.xlsx` в архив и сделайте следующий
замер: файлы создадутся с новой шапкой.
