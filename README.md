# UI2058E Toolkit

Автономное снятие данных с измерителя светодиодных светильников
**VOLNIC / Hangzhou Forward UI2058E** по USB — без фирменной программы.

Прибор отдаёт по последовательному порту (FTDI, 19200 8N1) полный набор
параметров: входное напряжение и ток, мощность, PF, частоту, гармоники,
а также **выход драйвера** — напряжение и ток на светодиодах, выходную
мощность и **готовый КПД (Efficiency)**.

Проект состоит из трёх частей:

| Файл | Назначение |
|------|------------|
| `ui2058_reader.py` | низкоуровневое чтение порта: один цикл измерения = 6 кадров |
| `ui2058_measure.py` | N циклов + усреднение, гармоники/THD, запись в CSV/XLSX, JSON для окна |
| `measure_gui.ps1` | окно оператора: артикул/образец/тест → кнопка → строка в общей таблице |

Протокол прибора разобран реверс-инжинирингом и описан в
[docs/protocol.md](docs/protocol.md).

---

## Возможности

- Чтение без `UI2058.exe` (фирменное ПО при этом должно быть закрыто — оно
  держит COM-порт).
- Автоопределение COM-порта адаптера FTDI (смена COM7 → COM9 ничего не ломает).
- Усреднение по нескольким циклам (1–20, по умолчанию 3) и разброс Urms.
- Вход: Urms, Irms, P, PF, Freq, Irmsw, PFw, CFv, CFi.
- Выход драйвера: Ulamp, Ilamp, Pout, IlrmsHi, **КПД (Efficiency с прибора)**.
- Гармоники U и I (H2, H3, H5, H7, H9, H11) и THDU/THDI — расчёт по
  осциллограммам, совпадает с показаниями прибора.
- Запись: архив по циклам `data/records/*.csv`, общая таблица
  `data/master.csv` + `data/master.xlsx`, опционально осциллограммы `data/waves/`.
- Кнопка «Копировать строку» — вставка одной строки в свою таблицу Excel.
- Автонумерация тестов по паре артикул+образец.

## Требования

- Windows 10/11 (проверено на Windows 11).
- Python 3.8+ (проверено на 3.14) и пакет `openpyxl` — см. `requirements.txt`.
  `pyserial` и `frida` нужны только для вспомогательных утилит.
- Драйвер FTDI CDM (адаптер `VID_0403 / PID_6015`, FT231X) — см.
  [drivers/README.md](drivers/README.md).
- Закрытая программа `UI2058.exe` во время замера.

Проще всего указать путь к интерпретатору переменной окружения
`UI2058_PYTHON`, если `python` в PATH — не тот, что нужен.
Окно само перебирает кандидатов и пропускает заглушку Microsoft Store
из `WindowsApps`.

## Быстрый старт

```bat
pip install -r requirements.txt
run_gui.cmd
```

Ярлык для рабочего стола (создаётся один раз, путь поправьте под себя):

```
%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe
  -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden
  -File "<путь к проекту>\measure_gui.ps1"
```

Порядок работы в окне:

1. Артикул, Образец, Тест № (кнопка «№ авто» подставит следующий номер).
2. Оператор (запоминается), комментарий — по желанию.
3. «Циклов» — сколько раз прочитать прибор и усреднить.
4. «СНЯТЬ ДАННЫЕ С ПРИБОРА» (или Ctrl+Enter).
5. При необходимости — «Копировать строку» и Ctrl+V в свою таблицу.

Подробнее: [docs/workflow.md](docs/workflow.md).
Настройка Windows, драйвера и COM-порта: [docs/windows-setup.md](docs/windows-setup.md).

## Что пишется в таблицу

`data/master.csv` и `data/master.xlsx` — одна строка на замер:

```
Дата и время | Артикул | Образец | Тест № | Оператор | Комментарий | Циклов
Urms | Irms | P | PF | Freq | v5 | Irmsw | PFw | CFv | CFi | v10..v14
THDU | THDI
H2 U | H3 U | H5 U | H7 U | H9 U | H11 U    (то же для тока)
Ulamp | Ilamp | Pout | IlrmsHi | КПД, %
Разброс Urms
```

`v5`, `v10`…`v14` — служебные поля прибора, оставлены как есть (могут
пригодиться при разборе режимов DC/RMS и коэффициентов).

`data/records/<дата>_<артикул>_<образец>_<тест>.csv` — по строке на цикл,
с min/max/rms осциллограмм.

## Командная строка

```bat
python ui2058_measure.py --article SPB-201 --sample 1 --test 5 --cycles 3
python ui2058_measure.py --article SPB-201 --sample 1 --test 5 --json
python ui2058_measure.py --article TEST --sample 0 --test 1 --wave
python ui2058_reader.py --seconds 10 --wave     :: сырые циклы в captures\
```

`--port COM7` можно указать явно, по умолчанию порт определяется сам.

## Ограничения

- Сейчас всё снимается в режиме **RMS**; переключатель DC/RMS прибора
  в программе не реализован.
- Гармоники считаются до H11; расширение до H39 — в планах.
- `THDIw` (взвешенный THD тока), который показывает прибор, не считается.
- Тест пускового тока (inrush) не реализован.
- `UI2058.exe` должна быть закрыта: порт открывается эксклюзивно.
