# Работа с окном замера

## Подготовка

1. Драйвер FTDI установлен, в диспетчере устройств есть
   «USB Serial Port (COMx)» — см. [windows-setup.md](windows-setup.md).
2. **`UI2058.exe` закрыта** — она держит COM-порт эксклюзивно.
3. Прибор включён, лампа подключена, на приборе выбран нужный режим.

Если порт занят, окно покажет: «порт занят. Закройте программу
UI2058.exe и повторите.»

## Поля окна

| Поле | Смысл |
|------|-------|
| Артикул | обозначение изделия, например `SPB-201-0-40K-048` |
| Образец | номер образца, например `01` |
| Тест № | номер замера; кнопка «№ авто» подставляет следующий для пары артикул+образец |
| Оператор | запоминается между запусками (`data/config.json`) |
| Комментарий | необязательно, попадёт в таблицу |
| Циклов | сколько раз прочитать прибор и усреднить (1–20, по умолчанию 3) |
| сохранять осциллограммы | дополнительно кладёт в `data/waves/` отсчёты U и I по каждому циклу |

Запуск: кнопка **«СНЯТЬ ДАННЫЕ С ПРИБОРА»** или `Ctrl+Enter`.
Окно на время замера блокирует кнопку — ждите, один цикл ≈ 1,4 с.

## Куда пишутся данные

```
data/master.csv      общая таблица, одна строка на замер
data/master.xlsx     она же в Excel (жирная шапка, закреплена первая строка)
data/records/*.csv   архив замера: строка на каждый цикл + min/max/rms
data/waves/*.csv     осциллограммы (если включён флажок)
```

Колонки общей таблицы:

```
Дата и время, Артикул, Образец, Тест №, Оператор, Комментарий, Циклов,
Urms В, Irms А, P Вт, PF, Freq Гц, v5, Irmsw А, PFw, CFv, CFi, v10..v14,
THDU %, THDI %,
H2 U, H3 U, H5 U, H7 U, H9 U, H11 U,  (аналогично для I)
Ulamp В, Ilamp А, Pout Вт, IlrmsHi А, КПД %,
Разброс Urms В
```

`v5`, `v10`…`v14` — служебные поля прибора, оставлены для будущего
разбора режимов.

## Кнопки внизу

| Кнопка | Действие |
|--------|----------|
| Копировать строку | последняя строка `master.csv` в буфер (табуляция) → `Ctrl+V` в свою таблицу |
| Папка данных | открыть `data/records` в проводнике |
| Общая таблица | открыть `data/master.xlsx` |
| Файл замера | открыть CSV последнего замера |

Вставка в Excel рассчитана на порядок колонок `master.csv`.
Если в вашей книге другой порядок — правьте строку вручную или
переставляйте колонки в книге.

## Замер из командной строки

```bat
python ui2058_measure.py --article SPB-201 --sample 1 --test 5 --cycles 3
python ui2058_measure.py --article SPB-201 --sample 1 --test 5 --json
python ui2058_measure.py --article SPB-201 --sample 1 --test 5 --cycles 5 --wave
```

- `--json` печатает результат в stdout (для скриптов),
- `--json-out <файл>` пишет JSON в файл (так работает окно),
- `--port COM7` — если автоопределение не сработало,
- `--wave` — сохранить осциллограммы.

Коды возврата: 0 — успех, 1 — ошибка (текст в `error`).

## Резервные копии

Перед изменениями кода сохраняйте копию в `versions\<дата>_<время>\`.
Папка исключена из git — это локальный архив для отката.
