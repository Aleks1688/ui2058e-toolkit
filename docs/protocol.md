# Протокол UI2058E

Описание получено реверс-инжинирингом: пассивный перехват обмена
фирменной программы (`tools/capture_live.py`, Frida + `ReadFile`/`WriteFile`)
и сверка чисел с экраном прибора (вкладка **Complex**).

## 1. Физический уровень

| Параметр | Значение |
|----------|----------|
| Прибор | VOLNIC / Hangzhou Forward UI2058E (тестер светодиодных ламп) |
| Кабель | USB → UART, FTDI **FT231X** (`VID_0403 / PID_6015`) |
| Драйвер | FTDI CDM (VCP), устройство `\Device\VCP0` → COM-порт |
| Линия | **19200 бит/с, 8N1**, без flow control |
| DTR / RTS | **выключены** (deasserted) |

Прошивка прибора, с которой снимались данные: `UI2058E V01.00`.

Порт открывается **эксклюзивно**: пока работает `UI2058.exe`, открыть
его снаружи нельзя (`Access denied`).

### Как именно открывается порт

Повторяет то, что делает `UI2058.exe` (см. `ui2058_reader.py`):

```
CreateFile("\\\\.\\COM7", GENERIC_READ|GENERIC_WRITE, 0, OPEN_EXISTING)
SetupComm(h, 4096, 1024)
SetCommMask(h, 0)
SetCommTimeouts: ReadIntervalTimeout = MAXDWORD,
                 ReadTotalTimeoutMultiplier = 0, ReadTotalTimeoutConstant = 0,
                 WriteTotalTimeoutMultiplier = 100, WriteTotalTimeoutConstant = 1000
DCB: 19200, 8, Parity=none, StopBits=1, fBinary=1,
     fDtrControl=0, fRtsControl=0, без XON/XOFF, fAbortOnError=0
EscapeCommFunction(CLRRTS); EscapeCommFunction(CLRDTR)
PurgeComm(PURGE_RXCLEAR) x2
```

Если поднять DTR/RTS, прибор отвечает только на запрос версии и молчит
на команды измерения.

## 2. Один цикл измерения

Цикл ≈ 1,3–1,5 с, всего принимается 2148 байт.

| Шаг | Отправка | Ответ | Смысл |
|-----|----------|-------|-------|
| 1 | `0x76` `'v'` | 16 байт ASCII | версия, `"UI2058E V01.00\r\n"` |
| 2 | `0x3F` `'?'` | 1 байт `0x21` | подтверждение |
| 3 | `0x32` `'2'` | 1 байт `0x00` | подтверждение |
| 4 | `0x21` `'!'` | 512 байт | осциллограмма A — **напряжение** |
| 5 | `0x21` `'!'` | 512 байт | осциллограмма B — **ток** |
| 6 | `0x21` `'!'` | 60 байт | **основные значения**, 15 × float32 |
| 7 | `0x21` `'!'` | 512 байт | осциллограмма C |
| 8 | `0x21` `'!'` | 512 байт | осциллограмма D |
| 9 | `0x21` `'!'` | 40 байт | **выход драйвера**, 10 × float32 |

Все float — little-endian IEEE-754 (`struct "<f"`), осциллограммы —
256 × `int16` (`"<256h"`).

Перед циклом порт «просушивается» (чтение всего накопленного в течение
0,15 с) и очищается `PurgeComm`. Ответы проверяются; при несовпадении
цикл повторяется (до 3 раз).

## 4. Кадр 40 байт — выход драйвера

| # | Поле | Ед. | Пример | Проверка |
|---|------|-----|--------|----------|
| 0 | **Ulamp** | В | 429,5 | экран (Complex) |
| 1 | **Ilamp** | А | 0,1049 | экран |
| 2 | **Pout** | Вт | 45,06 | экран |
| 3 | IlrmsHi | А | 0,0000 | экран |
| 4 | **Efficiency** | доля 0…1 | 0,959 | экран, «КПД %» |
| 5 | служебное | — | −0,6445 | |
| 6 | служебное | — | −2,7508 | |
| 7 | служебное | — | 2,1425 | |
| 8 | служебное | — | 2992,5 | |
| 9 | служебное (частота) | Гц | ≈49,995 | |

`Efficiency` — готовое значение прибора: `Pout / Pin` с точностью
до третьего знака (проверено: 45,05 / 46,89 = 0,9607 при поле 0,9607).
В таблицы пишется как проценты (`× 100`, один знак после запятой).
Если поле равно нулю (нагрузка не подключена), КПД не определён.

## 5. Осциллограммы и гармоники

Осциллограмма — 256 отсчётов на один период сети, `int16` (коды АЦП,
без калибровки в вольты). Для гармоник важен только относительный
уровень, поэтому масштаб не нужен.

Расчёт (как в `ui2058_measure.py`):

```
N = 256
для k = 1..40:
    re = Σ v[n]·cos(2πkn/N)
    im = Σ v[n]·sin(2πkn/N)
    A[k] = 2/N · hypot(re, im)
THD = sqrt(Σ A[k]², k=2..40) / A[1] · 100 %
Hk, % = A[k] / A[1] · 100 %
```

Если фундаментальная амплитуда меньше 10 кодов (нагрузка отключена),
гармоники не считаются — в таблицу пишется пусто.

Сверка с прибором (лампа SPP-201, 230 В):

| | прибор | наш расчёт |
|---|---|---|
| THDU | 0,98 % | 0,98 % |
| THDI | 8,98 % | 8,98 % |
| H3 I | 8,2 % | 8,18 % |
| H5 I | 1,0 % | 1,01 % |

Расхождение — в пределах округления индикатора.

## 6. Что пока не разобрано

- Кадры C и D (вторые 512 байт): предположительно напряжение/ток
  в другом режиме или «сырые» отсчёты АЦП; в расчётах не используются.
- Переключатель **DC/RMS** прибора: в протоколе не найден отдельный
  флаг режима. Сейчас всё снимается в RMS.
- `THDIw` (взвешенный THD тока, прибор показывает 14,72 % при THDI 8,98 %):
  формула взвешивания неизвестна.
- Тест пускового тока (inrush): кадры/команды не исследованы.

## 7. Наблюдения по железу

- Если закрыть `UI2058.exe` в момент, когда на приборе открыт диалог
  «выключите/включите лампу», прибор может перестать отвечать на все
  команды (`v`, `?`, `2`, `!`) — помогает только переподключение USB.
- Прибор не опрашивается, пока в фирменной программе не запущен тест.
  Нашему ридеру это не нужно: он сам инициирует цикл.
- При обрыве/переподключении адаптера Windows может «выключить»
  устройство (код 22) — тогда COM-порт пропадает. См.
  `docs/windows-setup.md`.
